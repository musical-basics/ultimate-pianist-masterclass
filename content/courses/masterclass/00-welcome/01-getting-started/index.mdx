## Plain prose

You can write paragraphs like this. Markdown formatting works: **bold**,
*italic*, [links](https://example.com), inline `code`, and so on.

Headings (`##`, `###`) become section breaks within the lesson. Lists work too:

- First idea
- Second idea
- Third idea

## Inline images

Standard markdown images work. Co-locate image assets inside an `assets/`
folder next to `index.mdx`, then reference them with a relative path:

```md
![A diagram of correct piano posture](./assets/posture.png)
```
